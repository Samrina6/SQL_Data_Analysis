# SQL Data Analysis

## Overview
This project demonstrates SQL-based data analysis on an e-commerce dataset using MySQL. It includes data querying, aggregation, table joins, subqueries, views, indexing, and query optimization techniques.

## Tools Used
- MySQL Command Line Client
- Visual Studio Code
- GitHub

## Dataset
- customers.csv
- orders.csv
- order_items.csv

## SQL Features Demonstrated
- SELECT
- WHERE
- ORDER BY
- GROUP BY
- Aggregate Functions (SUM, AVG)
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- Subqueries
- Views
- Indexes
- EXPLAIN

## Analysis Performed
- Retrieved and filtered records using SELECT and WHERE.
- Sorted data using ORDER BY.
- Grouped records using GROUP BY.
- Calculated totals and averages using SUM() and AVG().
- Combined tables using INNER JOIN, LEFT JOIN, and RIGHT JOIN.
- Used subqueries for advanced filtering.
- Created a view for simplified analysis.
- Created an index to improve query performance.
- Analyzed query execution using EXPLAIN.

## Outcome
Successfully analyzed structured e-commerce data using SQL and demonstrated fundamental data analysis techniques and query optimization in MySQL.
